# QR打刻ソフト

QRコードで出勤・退勤・休憩開始・休憩終了を記録する、オフライン利用向けのデスクトップ打刻アプリです。

React + TypeScript + Tauri 2で作られており、打刻データは端末内のSQLiteデータベースに保存されます。インターネット接続や外部サーバーは不要です。

## 使うだけの方はこちら

WindowsまたはmacOSで使うだけの場合、開発環境の準備やビルド作業は不要です。

1. 最新版の配布ページを開きます。

   https://github.com/Srtkst/offline-qr-timecard/releases/latest

2. 自分のPCに合うインストーラーをダウンロードします。

   - Windows: `.msi` または `.exe`
   - macOS: `.dmg`

3. ダウンロードしたファイルをダブルクリックしてインストールします。

4. QR打刻ソフトを起動します。

5. 初期状態では管理者PINに `1234` を入力します。

6. 初回ログイン後に、新しい管理者PINへ変更します。

データは各PCのアプリ用データ領域に保存されます。別PCへ移す場合は、アプリ内の「システム設定」からバックアップを作成し、移行先PCで「バックアップから復元」を実行してください。

## 主な機能

- QRコードを読み取って打刻を記録
- 出勤、退勤、休憩開始、休憩終了の4種類に対応
- 従業員の登録、編集、有効化・無効化
- 従業員ごとのQRコード表示・印刷・再発行
- 勤務日ごとの打刻履歴確認
- 期間指定によるCSV出力
- 事業所名、日付切り替え時刻、連続打刻上書き秒数の設定
- データベースのバックアップ・復元

## 動作に必要なもの

このアプリを開発環境で起動するには、以下を先にインストールしてください。

- Node.js LTS版
- npm
- Rust
- TauriのOS別依存パッケージ

Tauriの前提条件はOSごとに異なります。詳しくは公式ドキュメントを確認してください。

- Tauri 2 Prerequisites: https://v2.tauri.app/start/prerequisites/

macOSでは、次のコマンドでAppleの開発ツールを入れておく必要があります。

```bash
xcode-select --install
```

インストール後、ターミナルで次のコマンドが動くことを確認します。

```bash
node -v
npm -v
rustc --version
cargo --version
```

## インストール方法

1. このプロジェクトのフォルダへ移動します。

```bash
cd offline-qr-timecard
```

2. npmパッケージをインストールします。

```bash
npm install
```

3. 開発用アプリを起動します。

```bash
npm run tauri dev
```

起動すると、デスクトップアプリのウィンドウが開きます。

## 初回起動時の初期データ

初回起動時に、以下の設定が自動作成されます。開発モードでは動作確認用のテスト従業員も作成されます。

| 項目 | 初期値 |
| --- | --- |
| 事業所名 | QR打刻ソフト |
| 管理者PIN | 1234（初回ログイン後に変更必須） |
| 日付切り替え時刻 | 5時 |
| 連続打刻上書き秒数 | 10秒 |
| テスト従業員 | テスト 太郎（開発モードのみ） |
| テスト用QRトークン | TEST_TOKEN_123（開発モードのみ） |

管理画面へ入るときは、初期状態ではPINに `1234` を入力してください。初回ログイン後に新しいPINの設定が必要です。

## 基本的な使い方

### 1. 管理画面を開く

打刻画面の右下にある「管理画面」を押します。

PIN入力画面が出たら、初期状態では `1234` を入力します。初回ログイン後に新しいPINへ変更してください。

### 2. 従業員を登録する

管理画面の「従業員管理」で「新規登録」を押します。

名前と従業員番号を入力して「登録実行」を押すと、従業員が追加されます。登録時に、その従業員専用のQRトークンが自動生成されます。

### 3. QRコードを印刷する

従業員一覧の「印刷」を押すと、QRコードが表示されます。

「印刷する」を押して、従業員ごとのQRコードを紙などに印刷してください。

### 4. 打刻する

「打刻画面へ戻る」を押して、打刻画面へ戻ります。

出勤、退勤、休憩開始、休憩終了の中から打刻種別を選び、QRコードリーダーで従業員のQRコードを読み取ります。

QRコードリーダーは、キーボード入力として読み取った文字列を入力し、最後にEnterを送信する設定を想定しています。

### 5. テスト打刻する

開発モードでは、QRコードリーダーがない場合でも初期データで動作確認できます。

打刻画面を開いた状態で、キーボードから次の文字列を入力してEnterを押してください。

```text
TEST_TOKEN_123
```

「テスト 太郎さん: 出勤 (記録しました)」のようなメッセージが表示されれば、打刻できています。

## 管理画面の機能

### 従業員管理

- 従業員の新規登録
- 名前・従業員番号の編集
- 従業員の有効化・無効化
- QRコードの印刷
- QRコードの再発行

QRコードを再発行すると、古いQRコードは使えなくなります。

### 打刻履歴

勤務日を選択して、その日の打刻一覧を確認できます。

日付切り替え時刻より前の打刻は、前日の勤務日として扱われます。たとえば日付切り替え時刻が5時の場合、午前4時の打刻は前日の勤務日になります。

### CSV出力

開始日と終了日を指定して、打刻データをCSVファイルとして保存できます。

CSVには次の列が出力されます。

```text
従業員番号,名前,勤務日,出勤,退勤,休憩開始,休憩終了
```

### システム設定

以下を変更できます。

- 事業所名
- 日付切り替え時刻
- 連続打刻上書き秒数

連続打刻上書き秒数の範囲内に同じ従業員が再度打刻した場合、新しい打刻として追加せず、直前の打刻内容を更新します。QRコードの二重読み取り対策として使います。

### データ管理

「バックアップ作成」で現在のデータベースを `.db` ファイルとして保存できます。

「バックアップから復元」で過去のバックアップを読み込めます。復元すると現在のデータは上書きされるため、必要に応じて先にバックアップを作成してください。

## 開発用コマンド

| コマンド | 内容 |
| --- | --- |
| `npm install` | 依存パッケージをインストール |
| `npm run tauri dev` | Tauriアプリを開発モードで起動 |
| `npm run dev` | Viteのフロントエンドだけを起動 |
| `npm run build` | TypeScriptチェックとフロントエンドビルド |
| `npm run tauri build` | 配布用デスクトップアプリをビルド |
| `npm run preview` | ビルド済みフロントエンドをプレビュー |

通常の動作確認には `npm run tauri dev` を使ってください。`npm run dev` はブラウザ上でフロントエンドだけを起動するため、TauriのSQLiteやファイル保存機能は正しく動かない場合があります。

## 配布用インストーラーの作り方

GitHub ActionsでWindows用とmacOS用のインストーラーを自動作成します。

### 手動で作成する場合

1. GitHubのリポジトリページを開きます。

   https://github.com/Srtkst/offline-qr-timecard

2. `Actions` タブを開きます。

3. `Release installers` を選びます。

4. `Run workflow` を押します。

5. `version` に `v0.1.0` のようなリリース番号を入力して実行します。

6. 完了後、`Releases` に公開リリースが作られます。

7. 利用者は最新版ページからインストーラーをダウンロードできます。

### タグで作成する場合

開発者が次のようにタグをpushすると、同じワークフローが動きます。

```bash
git tag v0.1.0
git push origin v0.1.0
```

作成されたReleaseは公開状態です。利用者は最新版ページからインストーラーをダウンロードできます。

## データの保存場所

打刻データはTauriのアプリデータ領域にある `attendance.db` に保存されます。

このファイルはプロジェクトフォルダ内ではなく、OSが管理するアプリ用データフォルダに作られます。データ移行や保管が必要な場合は、アプリ内の「システム設定」からバックアップを作成してください。

## トラブルシューティング

### `npm` が見つからない

Node.jsが入っていないか、ターミナルがインストール後の環境を認識していません。Node.js LTS版をインストールし、ターミナルを再起動してください。

### `cargo` または `rustc` が見つからない

Rustが入っていないか、ターミナルがインストール後の環境を認識していません。Rustをインストールし、ターミナルを再起動してください。

### macOSでTauriの起動やビルドに失敗する

Appleの開発ツールが不足している可能性があります。

```bash
xcode-select --install
```

を実行してから、もう一度 `npm run tauri dev` を試してください。

### QRコードを読んでも「未登録のQRコードです」と出る

次を確認してください。

- 正しい従業員のQRコードを読んでいるか
- 従業員が無効化されていないか
- QRコード再発行後に古いQRコードを使っていないか
- QRコードリーダーが読み取り後にEnterを送信しているか

### データを別PCへ移したい

移行元PCで「システム設定」からバックアップを作成し、移行先PCで「バックアップから復元」を実行してください。
